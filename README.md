# باز کردن قفل گوشی با ESP32 (کیبورد بلوتوثی PIN)

یک پروژه‌ی ESP32 که به‌عنوان **کیبورد بلوتوثی (BLE)** به گوشی یا کامپیوتر وصل می‌شود و با یک بار زدن دکمه‌ی BOOT، رمز شما را به‌صورت خودکار تایپ می‌کند. پین‌ها از طریق یک صفحه‌ی وب روی وای‌فای خود دستگاه تنظیم می‌شوند.

## امکانات

- تایپ خودکار ۴ پین ترتیبی و بعد از آن پین اصلی، با فاصله‌ی ۸۰۰ میلی‌ثانیه
- گزینه‌ی ارسال Enter بعد از هر پین
- تا **۸ پروفایل** برای گوشی‌های مختلف، با انتخاب سریع از صفحه‌ی وب
- نام هر پروفایل خودکار از پین اصلی آن ساخته می‌شود
- ذخیره‌ی تنظیمات در حافظه‌ی فلش (بعد از خاموش شدن هم می‌مانند)
- صفحه‌ی تنظیمات موبایل‌پسند با حالت تیره
- پیام تأیید ذخیره داخل همان صفحه، بدون باز شدن صفحه‌ی جدید
- چراغ LED برای نشان‌دادن پایان تایپ

## سخت‌افزار

- برد ESP32 (مثلاً DevKit V1) با دکمه‌ی BOOT و LED داخلی روی پایه‌ی ۲
- کابل USB برای آپلود

## نرم‌افزار و کتابخانه‌ها

- [Arduino IDE](https://www.arduino.cc/en/software) با نصب بسته‌ی برد **ESP32**
- کتابخانه‌ی **HijelHID_BLEKeyboard** (باید جداگانه نصب شود)
- کتابخانه‌های `WiFi`، `WebServer`، `Preferences` و `ArduinoOTA` همراه بسته‌ی برد ESP32 نصب می‌شوند و نیاز به نصب جدا ندارند

## ساختار پروژه

```
firmware/
  Unlock_passcode_ESP32/
    Unlock_passcode_ESP32.ino          نسخه‌ی کامل (با آپدیت بی‌سیم OTA)
  Unlock_passcode_ESP32_no_OTA/
    Unlock_passcode_ESP32_no_OTA.ino   نسخه‌ی بدون OTA
  README.md
```

**کدام نسخه را استفاده کنم؟**

- **نسخه‌ی کامل:** بعد از اولین آپلود با کابل، می‌توانید کد را از طریق وای‌فای هم آپدیت کنید.
- **نسخه‌ی بدون OTA:** ساده‌تر و امن‌تر است، چون دستگاه آپدیت بی‌سیم ندارد و فقط با کابل USB آپلود می‌شود.

## نصب و آپلود

1. Arduino IDE را باز کنید و بسته‌ی برد ESP32 را از Boards Manager نصب کنید.
2. کتابخانه‌ی `HijelHID_BLEKeyboard` را نصب کنید.
3. یکی از دو فایل `.ino` را باز کنید.
4. **قبل از آپلود، رمز وای‌فای را عوض کنید** (خط `ap_password` در کد).
5. برد را از منوی Tools انتخاب کنید (مثلاً `ESP32 Dev Module`) و آپلود کنید.

## طرز استفاده

### ۱) تنظیم پین‌ها

1. به وای‌فای دستگاه وصل شوید: نام شبکه `ESP32-PinConfig` (رمز، همان است که در کد گذاشته‌اید).
2. در مرورگر آدرس `192.168.4.1` را باز کنید.
3. پروفایل را انتخاب کنید یا با **New** پروفایل جدید بسازید.
4. پین‌ها را وارد و **Save** را بزنید.

| بخش | کاربرد |
| --- | --- |
| PROFILE | انتخاب، ساخت و حذف پروفایل (حداکثر ۸) |
| DECOY PINS | ۴ پین ترتیبی که اول تایپ می‌شوند |
| REAL PIN | پین اصلی که آخر تایپ می‌شود |
| Send Enter after each PIN | ارسال Enter بعد از هر پین |

### ۲) جفت‌کردن بلوتوث

در بلوتوث گوشی دستگاهی با نام `ESP32 PIN Entry` را پیدا کنید و جفت (Pair) کنید.

### ۳) تایپ پین‌ها

| عمل | نتیجه |
| --- | --- |
| فشار کوتاه دکمه‌ی BOOT (کمتر از ۵ ثانیه) | تایپ پین‌های پروفایل فعال. بعد از پایان، بلوتوث خاموش می‌شود و LED پانزده بار چشمک می‌زند |
| نگه‌داشتن BOOT به مدت ۵ ثانیه (وقتی بلوتوث خاموش است) | روشن‌شدن دوباره‌ی بلوتوث، LED یک بار چشمک می‌زند |

برای تایپ، باید دستگاه به گوشی وصل (Connected) باشد.

## هشدارها

- این پروژه را **فقط روی دستگاه‌های شخصی خودتان** استفاده کنید.
- بسیاری از گوشی‌ها بعد از چند بار وارد کردن پین اشتباه، قفل موقت می‌شوند یا در حالت‌های امنیتی اطلاعات را پاک می‌کنند. قبل از استفاده، پین‌ها را با دقت وارد کنید.
- پین‌ها در حافظه‌ی فلش به‌صورت **متن ساده** ذخیره می‌شوند و هر کسی که به وای‌فای دستگاه وصل شود، آن‌ها را در صفحه‌ی وب می‌بیند. برای پین‌های بسیار حساس مناسب نیست.
- رمز وای‌فای پیش‌فرض داخل کد است. حتماً قبل از استفاده آن را عوض کنید.
- صفحه‌ی وب احراز هویت جداگانه ندارد و امنیت آن فقط به رمز وای‌فای بستگی دارد.
